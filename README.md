# 평가 기록 도우미 (T-record)

초등학교 담임교사가 **평소 관찰 한 줄을 담아 두면, 학기말에 학생별로 모여 학교생활기록부 문장이 되는** 웹앱입니다.

👉 **바로 쓰기: https://ssongssem.github.io/trecord/**

- 파일 하나(`index.html`)로 끝나는 정적 웹앱입니다. 설치·회원가입·서버가 없습니다.
- **모든 기록은 그 기기의 브라우저에만 저장됩니다.** 서버로 전송되지 않습니다.
- 산출물 사진은 IndexedDB에 따로 보관하고, 기록은 JSON으로 내보내고 가져올 수 있습니다.

## 무엇을 하나

| 단계 | 하는 일 |
|---|---|
| **준비** | 우리 반(학년·반·전담 교과·명렬) 등록, 학교 평가계획(**한글 HWPX**·PDF·표)에서 평가과제 가져오기 |
| | 평가 개발 — 성취기준 고르기 → 영역 자동 → 관찰 관점 → **루브릭 3수준 완성**(뼈대 만들기·점검) |
| **기록** | 관찰 한 줄 담기 — 학생 · 축(교과/창체/행동특성) · **근거 유형** · 성취기준 태그 · 수준 · 산출물 사진 |
| | 담긴 근거를 보며 기록 문장 작성 → 기재요령 자동 검사 → 검증 게이트 → 복사 |
| **살펴보기** | 짚어주기(관찰이 빈 학생, 근거가 치우친 학생, 위반이 남은 문장…), 진행 현황, 백업 |
| **AI 연결** | 선택 사항. 본인 Google AI Studio 키를 넣으면 문장 검토·초안·산출물 사진 읽기가 켜집니다 |

학교 평가계획은 **한글 HWPX 파일을 그대로 끌어다 놓으면** 표를 행 단위로 읽습니다.
옛 형식인 `.hwp`는 읽지 못합니다 — 한글에서 **다른 이름으로 저장 → HWPX**로 저장한 뒤 올리거나,
PDF로 저장해 「AI로 읽기」를 쓰세요. (HWPX는 ZIP+XML이라 브라우저가 직접 풀 수 있지만,
`.hwp`는 옛 복합문서 형식이라 표의 행·열을 되살리기 어려워 지원하지 않습니다.)

## 근거를 남기는 도구입니다

학교생활기록부 서술형 항목의 근거로 삼을 수 있는 학생 산출 자료는
**동료평가서 · 자기평가서 · 수업산출물 · 소감문 · 독후감 5종**뿐입니다(2026학년도 기재요령 p.27-28).
그래서 이 도구는 관찰을 담을 때마다 **무엇을 보고 썼는지**를 함께 묻습니다.

## 기재요령 검사

두 등급으로 나눠 검사합니다.

- **등급 1(위반)** — 어학시험·자격증, 논문·출간·특허, 장학금·기부·해외활동, 국제기구명,
  상표·앱 실명(→ 일반명사 치환 제안), 특수문자·이모지. 고치기 전에는 복사가 잠깁니다.
- **등급 2(확인)** — 대회·경시, 점수·등급·석차, 명사형 종결, 주어.
  뜻이 다를 수 있어(‘수상 안전 교육’, ‘3등분’, ‘자신의 의사’) 막지 않고 표시만 합니다.

낱말로 드러나지 않는 위반은 기계가 찾지 못합니다. 그래서 이 도구는 **‘이상 없음’이라고 말하지 않고**,
“자동 검사에서 발견된 항목 없음 — 자동 검사는 일부 유형만 찾습니다”라고 씁니다.
최종 확인은 교사가 합니다(기재요령 p.18, 2026학년도 신설).

## 자료

- 성취기준 **611건** — 2022 개정 교육과정 별책 원문(11교과, 학년군별)
- 평가 키워드 **688개** — 성취기준을 관찰 관점으로 압축한 것 + 축별 팔레트
- 학교 평가계획의 **2015 개정 코드**는 문장 유사도로 2022 개정 성취기준에 맞춰 추정합니다
  (코드가 같아도 뜻이 다른 경우가 많아 코드만으로 판단하지 않습니다)

## 고치고 빌드하기

```bash
python build.py     # app.src.html + 성취기준·키워드 JSON  →  index.html
```

`index.html`은 자체 포함 단일 파일입니다. 외부 요청이 없으므로 어디에 올려도 그대로 동작합니다.

## 공용 AI 연결 (선택)

키 없이도 다른 선생님이 AI 검토를 쓰게 하려면 [`proxy/README.md`](proxy/README.md)를 보세요.
**API 키를 `index.html`에 넣으면 안 됩니다** — 이 저장소는 공개라 소스에서 그대로 읽히고,
시크릿 검사에 걸려 폐기됩니다. 키는 중계 서버(Cloudflare Workers)에 두고 앱에는 주소만 넣습니다.
